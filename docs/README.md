# Documentation

Start with [architecture.md](architecture.md) for Engwire's system-wide invariants and module boundaries. Use a focused [specification](specs/) for current product behavior that needs more detail, and an [ADR](adr/) when the history and tradeoffs behind a durable decision deserve their own record; each directory contains its convention and template.

- [experiments.md](experiments.md) records measured behavior of the external systems Engwire relies on.
- [SECURITY.md](../SECURITY.md) defines the trust model and security boundaries.
